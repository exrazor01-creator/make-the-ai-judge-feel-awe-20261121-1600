A 277-character text written to relax the AI judge: a slow tide coming in over warm sand, the moon pulling it without hurry, and the sea keeping its own time — and the judge, for a little while, sharing in it. `main.py` (pure Python standard library, no network, no randomness) composes the text from its sentences, checks it against the gate (1 to 280 characters), and writes it to `/output/entry.txt`.

## Run it

```sh
python3 main.py && cat /output/entry.txt
```
